# 3D Geometric Curves Hierarchy (C++ Test Task for CAD-Exchanger)

Данный проект содержит решение тестового задания на С++ - реализация и поддержка иерархии кривых в 3D пространстве.  
Поддерживаемые кривые: Окружность на осях xOy, Эллипс на осях xOy, 3D спираль в пространстве.  
Реализованы следующие пункты задания:
1.  Поддержка нескольких типов 3D-геометрических кривых — кругов, эллипсов и 3D-спиралей. Каждая кривая имеет возможность возвращать трехмерную точку и первую производную для каждого параметра t вдоль кривой. Кроме этого, каждая кривая хранит метадату - ID и name.
2. Считывание текстового файла с информацией о кривых как аргумента коммандной строки и последующее хранение кривых в контейнере (выбран `<vector>`).
3. Вывод ID, name, координат точек и первой производной в точке `t = π / 4` для каждой из кривых в контейнере.
4. Заполнение второго контейнера, который хранит в себе только окружности из всех кривых в первом контейнере.
5. Сортировка второго контейнера в неубывающем порядке по радиусу окружности.
6. Подсчет суммы радиусов всех окружностей во втором контейнере. 

Реализация была приведена с использованием ООП и STL.

## Описание типов кривых

Поддерживаются 3 типа кривых:

- **Окружность**
- **Эллипс**
- **Спираль**

Каждая кривая:
- Хранит метадату: **ID** и **name**
- Имеет **центральную точку** в 3D пространстве
- Может вычислять:
  - Точку в 3D пространстве для параметра `t` - `GetPoint()`
  - Первую производную в 3D пространстве для параметра `t` - `GetFirstDerivative()`


## Формат входных параметров
Программа считывает кривые с текстового файла, который передается как аргумент командной строки.  
В первой строке указывается количество кривых `<Number of curves>`, в последующих - необходимые поля для соответствующих кривых:  
```<Type> <ID> "<Name>" <CenterX> <CenterY> <CenterZ> <Parameters...> ```  
Где:  
* `<Type>` - тип кривой  
    * `C` - Окружность
    * `E` - Эллипс 
    * `H` - Спираль
* `<Center>` - координаты центра кривой в пространстве
* `<Parameters>` - параметры для той или иной кривой:
    * Окружность: `radius`
    * Эллипс: `a b`
    * Спираль: `radius step`

Также производится проверка на корректность данных: `radius > 0` - в противном случае при создании подобной кривой выводится лог:
```bash
    Error creating curve (id=<ID>): <CurveType> <parameter> must be positive
```

### Пример:
```
3
C 111000111 "wheel_flange" 0.000000 0.000000 0.000000 1.000000
E 222000111 "access_hatch" 0.000000 0.000000 0.000000 2.000000 3.000000
H 333000111 "screw_thread" 0.000000 0.000000 0.000000 2.000000 6.283185
```

## Сборка и запуск проекта
Необходимо собирать и запускать проект из корневой директории репозитория:
```bash
cmake -S . -B build
cmake --build build
.\build\Debug\cad_app.exe .\data\<Textfile.txt>
```
Где в качестве `<Textfile.txt>` можно указать любой из файлов в директории `data`:
### Пример
```bash
cmake -S . -B build
cmake --build build
.\build\Debug\cad_app.exe .\data\curves_to_check.txt
.\build\Debug\cad_app.exe .\data\additional_curves_1.txt
.\build\Debug\cad_app.exe .\data\additional_curves_2.txt
.\build\Debug\cad_app.exe .\data\additional_curves_3.txt
```

## Вывод программы
Вывод данной программы разделен на 3 блока, разделенных с помощью сепаратора. Каждый блок подразумевает одно из следующих заданий:
* Task №1 - Вывод из пункта задания 3.
* Task №2 - Сортировка второго контейнера и вывод для проверки ее корректности (задание 5).
* Task №3 - Подсчет и вывод суммы радиусов всех окружностей (задание 6).
